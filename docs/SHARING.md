# Video Cross Search：共有・起動手順書

対象：Windowsで、このアプリを初めて受け取る人。作成日：2026-11-17。

YouTubeとニコニコ動画を一つの画面で検索し、1回につき各サイト最大6本を交互に表示します。
カードを押すと元サイトが別タブで開きます。最初の画面には固定の動画12本を表示します。

## 1. 共有する人が行うこと

リポジトリは公開（Public）です。閲覧とZIPのダウンロードに、GitHubへのログインや招待の承諾は不要です。

相手に次の2つのURLを送ってください。

- [リポジトリ](https://github.com/yagirixu-oss/video-cross-search)
- [この共有・起動手順書](https://github.com/yagirixu-oss/video-cross-search/blob/main/docs/SHARING.md)

配布用のZIPはリポジトリの Code → Download ZIP から取得できます。
自分の作業フォルダをそのままZIPにすると、秘密の.envや大きな.venvが混ざるため、配布にはGitHubから取得したZIPを使ってください。
コードを直接変更する共同作業者の招待は、閲覧・試用とは別の設定です。

この手順は**各自のPCにアプリを用意して動かす方式**です。ブラウザだけで利用できる公開サイトのURLはまだありません。
`127.0.0.1` は「今使っている自分のPC」を指します。他の人へそのURLを送っても、共有元のPCにはつながりません。

## 2. 受け取る人が準備するもの

- WindowsのPCとインターネット接続。
- Python 3.10以上。これまでの動作確認環境は3.10.11で、すべての新しい版を検証したわけではありません。
- YouTube検索も使う場合は、自分で作成したYouTube Data API v3用のAPIキー。

Pythonは[公式配布ページ](https://www.python.org/downloads/windows/)からインストールできます。
PowerShellで次を実行し、バージョンが表示されるか確認します。

```powershell
# ── Pythonが使用できるか確認 ──────────────────
python --version
```

認識されない場合は `py --version` も確認してください。pyだけ使える環境では、後の `python -m venv .venv` を `py -m venv .venv` に置き換えます。
どちらも動かない場合はPythonのインストールを済ませ、PowerShellを開き直してください。

## 3. ソースをダウンロードして展開する

1. ブラウザを開きます。GitHubへのログインは不要です。
2. [リポジトリ](https://github.com/yagirixu-oss/video-cross-search)を開き、Code → Download ZIP を選びます。
3. ZIPを右クリックして「すべて展開」を実行します。ZIPの中から直接実行しないでください。
4. 展開したフォルダを開き、**README.md・backend・frontendが一緒にある階層**まで移動します。
5. エクスプローラーのアドレス欄に `powershell` と入力してEnterを押します。

この階層を「プロジェクトのルート」と呼びます。ZIPによって同名フォルダが二重になっていても、上記3項目が見える階層を選べば大丈夫です。
配布されたZIPを受け取った場合は、上記3から進めてください。

## 4. 初回の準備

**プロジェクトのルート**で、次を一行ずつ実行します。エラーが出たら先へ進まず、その行とメッセージを確認してください。

```powershell
# ── 専用のPython環境を作る（初回のみ） ──────────
# .venvはこのアプリ専用のPythonとライブラリを置くフォルダ。
python -m venv .venv

# ── 必要なライブラリをインストール ──────────────
# 固定したバージョンのFastAPIなどを、作成した環境に入れる。
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
```

`.venv` はGitHubのZIPに含まれません。新しい場所に展開したときは、その場所で作成してください。
仮想環境のactivateは不要です。上記コマンドは使用するPythonを直接指定しています。
pipの更新通知だけならエラーではありません。

## 5. YouTube検索を設定する

固定一覧とニコニコ検索だけを試す場合は、この節を飛ばして起動できます。
YouTube検索を使う人は、それぞれのキーを用意します。共有元のキーは配布物に含まれていません。

1. [Google Cloud Console](https://console.cloud.google.com/)にログインします。
2. 上部のプロジェクト選択から新しいプロジェクトを作成します。名前の例は `video-cross-search` です。
3. 作成したプロジェクトを選び、YouTube Data API v3を検索して「有効にする」を押します。
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」でキーを作成します。
5. キーの編集画面で「APIの制限」をYouTube Data API v3に限定して保存します。

このアプリはPythonサーバーから接続します。ブラウザの参照元を指定する「ウェブサイト」のアプリケーション制限は使いません。
ローカル動作確認ではアプリケーションの制限を「なし」にし、上記のAPI制限を設定します。公開運用は別途設定を検討してください。
Google側の基本手順は[公式ガイド](https://developers.google.com/youtube/data/getting-started)も参照してください。

続いて、プロジェクトのルートで次を実行します。

```powershell
# ── 設定ファイルを作成して開く ──────────────────
# .envがすでにある場合は上書きせず、そのファイルを開く。
if (-not (Test-Path backend/.env)) {
    Copy-Item backend/.env.example backend/.env
}
notepad backend/.env
```

開いたファイルの該当行を次の形にして保存します。右側だけを実際のキーに置き換えてください。

```dotenv
YOUTUBE_API_KEY=ここを自分のAPIキーに置き換える
```

ファイルは **backend/.env** に保存します。`.env.txt` ではありません。
キーや.envをGitHub・チャット・共有ZIPへ載せないでください。キーが映るスクリーンショットも送らないでください。
.gitignoreは.envをGitの管理対象から除外しますが、手作業での添付やZIP作成までは防げません。

## 6. 起動する

プロジェクトのルートから、次を実行します。

```powershell
# ── バックエンドのフォルダへ移動 ────────────────
cd backend

# ── 【根幹】画面とAPIをまとめて起動 ──────────────
# 127.0.0.1を指定し、このPCから利用する開発サーバーとして起動する。
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

`Application startup complete.` が出たら、ブラウザで **http://127.0.0.1:8000/** を開きます。
使用中はPowerShellを開いたままにします。停止するときは、そのPowerShellでCtrl+Cを押します。

**Live ServerのGo Live、5500番ポート、index.htmlのダブルクリックでは起動しません。**
この構成ではFastAPIがCSS・JavaScriptも配信するため、8000番のトップ画面を使います。
`/api/videos` はプログラム向けのデータ表示で、カード画面ではありません。

## 7. 動作を確認する

1. 最初の画面で固定動画が12本表示されることを確認します。広い画面では4列×3行です。
2. 「初音ミク」などの検索語を入れて検索します。
3. キーを設定した場合は、YouTubeとニコニコの取得件数が表示されることを確認します。
4. 両サイトのカードをそれぞれ一つ押し、対応する動画ページが別タブで開くことを確認します。
5. 下部の「もっと見る」を押し、既存の動画が残ったまま件数が増えることを確認します。続きがない場合はボタンが消えます。
6. 「固定の一覧に戻す」で最初の12本へ戻ることを確認します。

検索結果は1回につき各サイト最大6本です。検索語や取得状況によって12本未満になるのは正常です。
YouTubeは関連度順、ニコニコは再生数順です。一方が失敗しても、成功した側の結果と失敗理由を表示します。

## 8. 次回の起動・更新

同じフォルダを使う場合は、backendフォルダでPowerShellを開き、手順6の最後の起動コマンドだけを実行します。
毎回Python環境を作る必要はありません。.envを変更した場合はサーバーを停止して起動し直してください。

更新時はサーバーを停止し、最新ZIPを**別フォルダへ展開**して手順4を実行します。
自分の.envや変更した動画データが必要なら、新しいフォルダへ手元で移してください。旧フォルダは確認が済むまで残します。
新しい版を起動し、ブラウザでCtrl+F5を押して再読み込みします。

## 9. よくある問題

| 症状 | 確認すること |
|---|---|
| GitHubが404 | 上記の正しいリポジトリURLを開き直す。現在は公開されているため、招待は不要 |
| pythonが認識されない | 手順2を確認する。pyが使えるなら環境作成時だけpyへ置き換える |
| .venvのpython.exeが見つからない | 手順4を実行したか、現在地がルートかbackendかを確認する |
| requirements-lock.txtが見つからない | 手順4はREADME.mdのあるルートで実行する |
| No module named uvicorn / dotenv | このフォルダの.venvで手順4のインストールを完了させる |
| 文字だけでデザインがない | 5500番ではなく http://127.0.0.1:8000/ を開く |
| 接続できない | サーバーの起動成功と、PowerShellを閉じていないことを確認する |
| ポート8000が使用中 | すでに起動したサーバーがあれば、そのPowerShellでCtrl+Cを押して停止する |
| YouTubeが未設定 | backend/.envの名前と保存場所、YOUTUBE_API_KEYの記入を確認して再起動する |
| YouTubeの設定エラー | 正しいプロジェクトでAPIが有効か、キーのAPI制限がYouTube Data API v3かを確認する |
| 利用枠・混雑のエラー | 画面の案内に従って待つ。Google Cloudで使用量を確認する。連打はしない |

PowerShellでYOUTUBE_API_KEY環境変数を設定済みの場合は、.envより環境変数が優先されます。
問題を報告するときは、実行したコマンド・エラー文・現在のフォルダを伝え、APIキーは含めないでください。
