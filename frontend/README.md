# 動画一覧画面

## 検索対象の選択

選択欄で両方・YouTubeのみ・ニコニコのみを指定し、検索ボタンで実行します。
対象を変えて再検索すると既存一覧・カーソル・件数をリセットします。固定一覧は従来どおり両サイト12本です。
選択欄の値と実行済み対象currentTargetを分離し、編集中も続き・再試行には元の条件を送ります。
一覧上部に実行済み対象を表示し、対象外サイトの件数・エラー案内は表示しません。

HTML / CSS / JavaScriptのみの小さな実装です。Node.jsやnpmの導入は不要です。

- index.html: 見出し、読み込み状態、カードを入れる場所。
- styles.css: 4列の配置、色、狭い画面での列数変更。
- app.js: API取得、カード作成、失敗時の再試行。
- favicon.svg: ブラウザのタブ用アイコン。

## 確認方法
ルートREADMEの手順でFastAPIを起動し、http://127.0.0.1:8000/ を開きます。
HTMLをダブルクリックして直接開く方法では動きません。
画面とAPIが同じサーバーなので、APIのURLやCORSを追加設定する必要はありません。

## 表示仕様
PCでは4列×3行、1000px以下では3列、760px以下では2列、440px以下では1列です。
12本はAPIの順序のまま表示します。件数表示は返却数から計算します。
video_urlがnullのカードはリンクを持たず、準備中と表示します。
URLを登録した動画は元サイトを別タブで開きます。
取得には15秒の待ち時間上限があり、失敗時は再試行ボタンを表示します。
画像の取得失敗ではカードを残して代替テキストを表示します。

## チームでの変更
デザインはHTMLとCSS、通信やカード組み立てはapp.jsを編集してください。
別のフロント開発サーバーへ移す場合はAPIの接続先とCORSの調整が必要です。
受け渡すデータは ../docs/API.md を参照してください。


## 検索画面

検索フォームは /api/search?q=検索語 を呼び、固定一覧と同じカードを使います。
サイト別の取得件数・失敗理由を表示し、一方が失敗しても他方の結果を残します。
検索結果ゼロと通信失敗は別の表示です。「固定の一覧に戻す」で最初の12本へ戻ります。
再検索では前の通信を中断し、遅れて返った古い結果で画面を上書きしません。
日本語変換中のEnterでは検索を送信しません。タイトル等はtextContentで表示します。
APIキーはHTMLやJavaScriptに記入せず、バックエンドの.envで管理してください。


## 続きの追加表示

「もっと見る」は検索結果の下部に表示し、クリック時だけnext_cursor付きで通信します。
初回検索では一覧を置き換え、追加取得では一覧の末尾へ追加します。動画IDをMapで管理し、重複を除きます。
読み込み中は追加・再試行ボタンを無効化します。別キーワードで検索した場合は前の通信を中断し、遅い結果の上書きを防ぎます。
片方の失敗はretry_cursorでそのサイトだけを再試行できます。通信エラーは今回の要求を再送し、成功分のカードは消しません。
410のときは「同じキーワードで検索し直す」を表示します。続きがなければ追加ボタンを消して終了を案内します。

## 並び順の選択

選択欄と実行済みcurrentSortを分離します。選択を編集中でも追加取得・再試行は元のsortを送ります。
再検索で一覧を置き換え、固定一覧へ戻ると並び順を標準に戻します。見出しには実行済みの並び順を表示します。


## v0.6での追加

投稿期間も実行済み条件として保持します。選択だけでは変わらず、「検索」で新しい一覧に置き換わります。続き・再試行には同じperiodを渡してください。詳細は [追加情報と期間の解説](../docs/SEARCH-DETAILS.md) を参照してください。
